ติดตั้ง

uv tool install graphifyy graphify install

ติดตั้งระดับโปรเจกต์

graphify install --project graphify install --platform opencode

เพิ่มความสามารถ

uv tool install "graphifyy[pdf]" uv tool install "graphifyy[video]"

ผลลัพธ์

graphify-out/graph.html graphify-out/GRAPH_REPORT.md graphify-out/graph.json

ต้องมี Python 3.10+ และ uv/pipx. PyPI ใช้ชื่อ graphifyy; CLI ใช้ graphify

คำสั่งทั้งหมด

    ไม่พบคำสั่งที่ตรงกับคำค้นหรือหมวดที่เลือก ลองใช้คำสั้นลง หรือเลือกทั้งหมด

    สามไฟล์ที่ได้

    • graph.html เปิดใน browser คลิกโหนด กรอง และค้นหา
    • GRAPH_REPORT.md god nodes, communities และ surprising connections
    • graph.json query, path, explain ซ้ำได้โดยไม่ต้องอ่านไฟล์ดิบ

security-audit skill และหกเฟส

ไม่พบรายการที่ตรงกับคำค้นหรือหมวดที่เลือก ลองใช้คำสั้นลง หรือเลือกทั้งหมด

สามคำตัดสิน

  • confirmed source trace ครบ + demonstrated impact; มี severity
  • needs_validation source-grounded แต่ blocker ยังชี้ชัด; ไม่มี severity
  • rejected ถูกหักล้างด้วย source หรือ local evidence; เก็บไว้กันอ้างซ้ำ

หลักที่ห้ามละ

  • ยืนยันเฉพาะ boundary failure ที่พิสูจน์ได้
  • เอเจนต์ที่ตรวจต้องไม่ใช่เอเจนต์ที่พบ
  • severity ต้องมาจาก impact ไม่ใช่ checklist deviation
  • defense-in-depth gap ที่มีชั้นอื่นกันอยู่ไม่ใช่ช่องโหว่
  • หลาย run เพิ่ม coverage; run เดียวไม่เท่ากับ exhaustive

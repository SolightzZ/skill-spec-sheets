เรียกใช้

Build a landing page for my SaaS product python3 .claude/skills/ui-ux-pro-max/scripts/search.py "beauty spa wellness" --design-system -p "Serenity Spa"

CLI ต้องมี Node.js; search.py ต้องมี Python 3.x

--global ใช้ได้ทุกโปรเจกต์; จัดการด้วย uipro update หรือ uninstall

skill mode เรียกเองเมื่อของาน UI/UX; slash command ใช้กับ Kiro, Roo Code และ KiloCode

สกิล ขั้นตอน และเอกสารอ้างอิงของ UI UX Pro Max

    ไม่พบรายการที่ตรงกับคำค้นหรือหมวดที่เลือก ลองใช้คำสั้นลง หรือกด “ทั้งหมด”

    ข้อมูลในเครื่อง

    • 192 product types / palettes / reasoning profiles
    • 79 searchable styles; 50 active, 29 supplemental, 9 deprecated
    • 74 font pairings; 1,934 Google Fonts
    • 119 UX guidelines; 25 charts; 105 icons
    • 17 GSAP presets; 34 landing patterns; 22 stacks
    • 1,272 stack guidelines; 1,512 Phosphor icons

    Anti-patterns

    • emoji ใช้แทน icon จริง
    • focus ลบ focus ring จน keyboard หลง
    • placeholder ใช้แทน label ถาวร
    • hover พึ่ง hover อย่างเดียว
    • colour ใช้สีอย่างเดียวสื่อความหมาย
    • fixed px container แข็งจนเกิด horizontal scroll

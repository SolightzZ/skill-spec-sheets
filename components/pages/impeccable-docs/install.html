ติดตั้ง (แนะนำ)

npx impeccable install /impeccable init npx impeccable update

รันในโปรเจกต์ที่ใช้ Node.js 18.19+ แล้วรีสตาร์ตเครื่องมือและอนุมัติ hook ใน Codex

ทางเลือก: plugin marketplace

/plugin marketplace add pbakaus/impeccable

Claude Code เท่านั้น: เพิ่ม marketplace, ติดตั้ง แล้วรัน /impeccable init

ทางเลือก: git submodule

git submodule add https://github.com/pbakaus/impeccable .impeccable npx impeccable link --source=.impeccable --providers=claude,cursor git submodule update --remote .impeccable

ใช้ Git แทน npx impeccable update; link สร้าง symlink

เรียกใช้

/impeccable <command> <target> /impeccable audit blog /impeccable critique landing $impeccable audit blog

Claude Code/Cursor/Copilot ใช้ /impeccable; Codex ใช้ $impeccable; ใช้ pin เมื่อต้องเรียกซ้ำ

ข้อมูลการใช้งาน

npx impeccable telemetry status npx impeccable telemetry off DO_NOT_TRACK=1 IMPECCABLE_NO_TELEMETRY=1

เปิดโดยค่าเริ่มต้น; ปิดด้วยคำสั่งด้านบน, DO_NOT_TRACK=1 หรือ telemetry: false
